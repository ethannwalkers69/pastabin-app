# 📝 Premium Pastebin

A beautiful, modern Pastebin web application with a stunning glassmorphism design. Built with Node.js, Express, and vanilla JavaScript.

## ✨ Features

- 🎨 **Dark Glassmorphism Design** - Stunning visual effects with backdrop blur
- ✨ **Floating Particles** - Dynamic background animations
- 📱 **Fully Responsive** - Works perfectly on all devices
- ⌨️ **Keyboard Shortcuts** - Boost your productivity
- 📊 **Character Counter** - Real-time text length tracking
- 🔔 **Toast Notifications** - Beautiful feedback system
- 🎯 **Micro-interactions** - Smooth animations throughout
- 🔒 **Secure Proxy** - Backend API proxy for security
- 🚀 **Production Ready** - Optimized for Render deployment

## 🛠️ Tech Stack

- **Backend:** Node.js + Express
- **Frontend:** Vanilla JavaScript (Single File Application)
- **Styling:** CSS3 with Glassmorphism
- **Hosting:** Render Web Service
